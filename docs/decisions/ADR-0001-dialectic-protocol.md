# ADR-0001：用四角色辩证协议替代单次生成

作者：晨星 · 状态：已接受

## 背景

单次生成的失败是静默的：模型编造内容时不留痕迹，事后无法判断哪句是查到的、哪句是猜的。

## 决策

引入 DP-4 协议：Proposer / FactChecker / Critic / Synthesizer 四角色多轮对抗。

- **反对必须引用证据跨度**，否则无效并丢弃
- **事实性由对齐判定，不由模型自述判定**
- **收敛定义 = 无有效反对**（不是"轮数用完"）

## 理由

1. 要求引用后才能反对，把"批评者"变成了可审计的角色，而不是一个会凭空质疑的噪声源。
2. 对齐判定（而非模型自述）是唯一能防"自称有据"的手段。
3. 收敛定义在语义上比"轮数上限"强：轮数用完只是放弃，无有效反对才是真的达成了一致。

## 代价

- 延迟：每轮 3 次模型调用（提案 / 核验 / 批评），最坏 9 次。生产上建议 `MAX_ROUNDS=2`。
- 小模型做 Critic 质量有限；协议靠"必须引用"这条规则兜底，不靠模型能力。

## 备选方案（未采用）

- 单次生成 + 事后 NLI 校验：只能判定，不能修正。
- 自洽投票（采样 N 次取多数）：对**事实错误**无效，多数样本会犯同一个错。辩衡把它作为可选增强（`SELF_CONSISTENCY`），不替代辩证。
